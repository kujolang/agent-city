# A clearer view of local agent work

Seeing local agent work clearly means knowing what is shown, what is true, and where the work ends up. That clearer view rests on three facts:

- Agent City is a local application that visualizes observed agent activity.
- The current runtime truth is separate from the animation.
- An author can hand a draft to a separate reviewer, and users can inspect the saved result.

This introduction is a local draft for review, not authorization to publish.
