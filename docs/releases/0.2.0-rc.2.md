# Agent City 0.2.0-rc.2 — local preview

A downloadable local application for supported author/reviewer, Kujo, evidence
and replay workflows. This is a release candidate, not general production
certification or complete execution support for every imported team.

## Install

On macOS Intel/Apple Silicon or Linux x64/ARM64:

```sh
curl --proto '=https' --tlsv1.2 -fsSL https://github.com/kujolang/agent-city/releases/download/v0.2.0-rc.2/install.sh | sh
```

The release installer pins the application commit and verifies its bootstrap
checksum, then installs the locked producer/runtime dependencies. It supplies
private Node when required and opens no model account. Existing installations are
not overwritten. Use a new directory with `sh -s -- --prefix /your/new/directory`,
or follow the documented explicit update procedure. Add `--no-start` to install
without launching. Network access to GitHub, npm and the pinned runtime sources
is required; this is not an offline installer.

After installation, the default launcher is:

```sh
"$HOME/.local/share/agent-city/start.command"
```

Open the displayed local URL. Configure Ollama through **Detect local Ollama**,
or use the installed Codex CLI and its ChatGPT login with the launcher's
`provider:codex` command. The app includes no account, API key or model weights.
For generated Kujo execution, install/start Docker separately, run
`setup:workcell --build --enable`, restart City, and explicitly opt into execution
for each task. Writing/review does not require Docker.

## Included and verified

- Local task submission, actual SDK author/reviewer handoff and saved results.
- Explicit local RAG/MCP/source context, isolated checks and Workcell execution.
- Six city locations/interiors, exact-instance Follow, truthful inspectors,
  health/gap status, archives, semantic replay and game-canvas recording.
- Saved Workcell configuration, guarded provider setup and exact selection recovery.
- 115 tests, boundary/map/build checks; four-platform installation CI.
- Native Chromium hidden/discard/resume on macOS and Linux; measured lifecycle-to-
  inspector latency. Synthetic stress is separate from real operation proofs.

See [qualification](../../RELEASE-QUALIFICATION.md), [workflow support](../workflow-support.md)
and [the real reviewed Kujo tool/video](../../evidence/reviewed-release-tool/README.md).
The release manifest pins exact source revisions and supported platforms.
SHA256SUMS verifies the installer, source archive and manifest; signing is not claimed.
The source archive is not a standalone compiled executable.

## Limits

WebOps/VideoOps profiles remain imported references with unconnected required
capabilities; their full team workflows are not advertised as executable. Existing
Publishing House proof covers draft/review, not publication. No public hosting,
Windows/Safari/Firefox certification, arbitrary tool grants or deployment control.
This Mac's graphics backend is slow even for bare WebGL; measured Linux results
are not a universal GPU guarantee. The cancelled eight-hour soak was not run, and
OS sleep is unqualified. Runtime truth is independent of recent visual activity.
