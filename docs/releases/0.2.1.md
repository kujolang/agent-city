# Agent City 0.2.1

Maintenance release for the supported local workflows in 0.2.0. Requires patched Node 24.22.1+ or 26.12.1+; the installer prepares private Node 24.22.1. Updates Vite and Vitest and preserves the local file-serving boundary. Consumer metadata pins Watchdog 1.2.1.

The existing workflow scope and exclusions remain: no multi-user hosted certification, no eight-hour soak, and no universal model or GPU guarantee. Four-platform installation acceptance must pass on this release commit before publication.
