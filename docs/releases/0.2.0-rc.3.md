# Agent City 0.2.0-rc.3 — release review draft

**Not yet published or release-qualified.** This next local preview adds selected
WebOps and VideoOps workflows to the existing real author/reviewer, Kujo execution,
Observer and replay experience. It is not a universal agent platform certification.

## Changes

- WebOps Reporter → Copy Chief → deterministic supplied-evidence report checks.
- Saved immutable VideoOps Docker image/context and explicit model capability setup.
- Actual SDK planning, asset resolution and Editor stages, offline isolated render,
  exact-candidate review, checksum-bound finalization and local download.
- Bounded acquired-media transport with verified hashes/rights evidence. The initial
  Mission Command launch surface supports silent original typography/vector work;
  external speech/music/media generation is not supplied by that form.
- Corrected planning guidance so inline CSS/SVG/text is composition code rather
  than a fabricated missing acquired asset. Required real media stays gated.
- Engine security preflight rejects missing seccomp/AppArmor before model work. Docker Desktop without AppArmor is not a qualified Workcell backend.
- Updated README and setup/review documentation.

## Requirements and limits

macOS Intel/Apple Silicon or Linux x64/ARM64; your own Ollama-compatible provider
or existing authenticated Codex CLI. The installer supplies private Node and pinned
Kujo dependencies. Docker is optional for writing/review and required for isolated
execution/rendering. No model accounts, API keys or model weights are bundled.
VideoOps image measured1.26GB on local amd64; build cache needs extra space.

Original artwork is inspired by the supplied references; no protected game assets
are shipped. Replay does not execute source work. No public hosting, arbitrary
imported workflow execution, long-duration stability certification or eight-hour
soak is claimed. Human review remains required for the exact video candidate.
