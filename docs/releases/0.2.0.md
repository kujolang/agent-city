# Agent City 0.2.0

Final release of the rc.3 functionality for documented local workflows. This is
not public hosting, universal agent-tool execution or long-duration certification.

## Included

- Truthful pixel-city Observer, interiors, Follow, inspectors, archive and deterministic replay.
- Explicit local writing/Kujo tasks, separate reviewer handoffs, scoped MCP reads,
  permitted Workcell execution, retained failures/checks and saved artifacts.
- Bounded WebOps reporting and real VideoOps planning, media resolution, isolated
  rendering, exact-candidate review, finalization and checksum-matching downloads.
- Pixel v2 product captures/font, verified media packs/uploads, optional separately
  authorized ElevenLabs audio, provenance and audio QA.
- Pinned macOS Intel/ARM and Linux x64/ARM installer with local setup documentation.

## Qualification and limits

The rc.3 runtime is unchanged. Its real production/video approval and failure
history remain valid; final-source CI and public distribution receipts are recorded
in [0.2.0 release evidence](../../evidence/release-0.2.0/README.md).

Users provide model accounts and optional media-provider entitlement. Fresh
ElevenLabs music/SFX generation is not live-qualified by the reused-audio demo.
Workcell requires a compatible seccomp/AppArmor engine. Imported profiles do not
enable arbitrary workflows/tools. No eight-hour soak or OS sleep certification.
The hardening assessment stays CONDITIONAL; version promotion does not turn an
unrun reliability test into a pass. See [qualification](../../RELEASE-QUALIFICATION.md).

Install: follow the [versioned installation guide](../../installer/README.md).
