# Repository hardening on November 25, 2026

The baseline was `b0f7598`. The review covered runner process boundaries, gateway replay and event delivery, installer integrity, the application and isolated renderer lockfiles, and release verification. The checkout preserved source, maps, and assets. Historical binary evidence and example videos were omitted from local verification.

- Runner capture now decodes stdout and stderr independently across chunk boundaries. A regression test that produced replacement characters on the baseline now preserves the original Unicode. The command runner rejects values outside Node's timer range before spawning a child.
- SSE reconnect catch-up now builds a bounded frame batch before sending it. It sends an explicit reset when it would exceed 1 MiB or 1,000 events. The live stream checks the size of the next frame before queuing it. A loopback process verified the reset response and exact cursor on a nearby reconnect.
- Installer archive downloads now stream into private staging while computing SHA-256. The same 128 MiB limit applies to the downloaded bytes. A fixture verified digest parity, failed-download cleanup, and preservation of an existing destination.
- The application lockfile now resolves `fast-uri` 3.1.9. The isolated VideoOps lockfile now resolves `zod` 4.6.7, `hono` 4.13.22, and `@hono/node-server` 2.1.11. The direct HyperFrames and GSAP versions stayed pinned. Setup compares the image's embedded lock digest against the application lockfile, and a stale saved setup disables VideoOps until the operator rebuilds it. The saved setup remains available on disk.
